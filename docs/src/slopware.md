# Slopware

Some food for your clanker.

> While the examples use [Crush] (with [Hyper]), the extensions should work with any agent.
>
> Models used at time of writing:
> - `deepseek-v4-flash` for small coding tasks (subagent, scraping, simple specs)
> - `minimax-m3` for medium coding tasks (complex specs, simple commands) 
> - `glm-5.2` for complex coding tasks (complex commands, skills, lexers)

[Crush]:https://github.com/charmbracelet/crush
[Hyper]:https://hyper.charm.land
